# 引路网站：完整试用版

这是「引路」的前端试用版源代码，单独存放在本目录，和之前的“引路网站”原型互不影响。

## 当前项目结构

当前版本采用“单页入口 + 多个页面视图”的结构。所有主要页面都写在 `index.html` 中，通过 `data-view` 和 `data-view-target` 在页面之间切换；这样可以先集中完成 HTML 页面骨架和导航关系，后续再逐步拆分或接入后端。

```text
yinlu-decision/
├── index.html              页面入口和所有主要页面结构
├── styles.css              全局样式和响应式样式
├── app.js                  导航、表单和本地试用交互
├── lib/lucide-lite.js      本地图标脚本
└── favicon.svg             网站图标
```

## 页面清单和命名

| 页面名称 | HTML 视图 ID | 导航名称 | 主要内容 |
| --- | --- | --- | --- |
| 首页 | `view-home` | 首页 | 决策阶段、搜索入口、平台介绍 |
| 院校与经验库 | `view-experience` | 院校与经验 | 院校信息、学生经验、筛选和搜索 |
| 问答中心 | `view-questions` | 问答中心 | 我要提问、我要回答、历史记录 |
| 我的候选 | `view-compare` | 我的候选 | 收藏候选和家庭协同决策 |
| 信任与认证 | `view-trust` | 信任与认证 | 身份认证和信息来源规则 |

导航按钮使用 `data-view`，页面内跳转按钮使用 `data-view-target`。例如：

```html
<button data-view="experience">院校与经验</button>
<button data-view-target="questions">去问答中心</button>
```

第一天的完成标准是：页面可以打开，主要页面有清晰结构，导航名称统一，页面之间可以正常切换。

## 已实现

- 高考志愿、考研择校、职业选择、大学适应四个决策阶段
- 院校信息与学生经验库、搜索筛选和同高中优先排序
- 注册、登录、退出和个人资料修改
- 问答中心的匿名提问、我要回答和历史记录
- 学校/专业候选收藏和对比
- 家庭关联邀请码生成与复制
- 校园身份认证申请状态
- 刷新页面后保留试用数据
- 响应式布局，支持手机浏览

## 运行

在本目录运行：

```powershell
python -m http.server 4173
```

然后打开：`http://localhost:4173/`

也可以直接双击 `index.html` 浏览，但使用本地 HTTP 服务更稳定。

## 重要说明

这是前端试用版，不是真实的多用户账号系统。账号、密码、问题、收藏、邀请码和认证申请仅保存在当前浏览器的 `localStorage` 中：

- 换浏览器、换设备或清理浏览器数据后，记录不会同步
- 账号密码不应填写真实敏感信息
- 认证申请只是产品流程演示，不会连接真实身份核验
- 页面内学校、经验和数据是产品展示用示例，正式上线前需要接入后端数据库、短信/邮箱认证、身份核验、内容审核和权限控制

后续要做成真正可供多人使用的平台，需要再增加后端服务和数据库；当前目录可以直接作为 GitHub Pages 的静态试用版源码。

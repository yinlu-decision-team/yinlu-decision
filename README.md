# 引路 - 人生决策与经验交流平台

**版本**：2026-08-14 最终集成版
**项目类型**：前端单页应用（SPA）

「引路」面向处在人生选择阶段的学生和家庭，围绕高考志愿、考研择校、职业选择与大学适应，提供院校信息、真实经验、问答交流、候选对比和家庭协同功能。

## 在线预览

GitHub Pages：<https://yjnon8oo.github.io/yinlu-decision/>

## 已实现功能

- 四个决策阶段：高考志愿、考研择校、职业选择、大学适应
- 院校与经验库：学校、专业、关注维度和信息来源筛选
- 横版与竖版布局切换，并在浏览器中保留布局偏好
- 问答中心：匿名提问、回答问题和历史记录
- 学校与专业候选收藏、状态管理和对比
- 用户注册、登录、退出和个人资料设置
- 头像、昵称、出生日期、注册日期及省市地区资料
- 家庭关联：学生生成邀请码，家长输入邀请码加入家庭
- 校园身份认证申请和状态展示
- 12 套可切换主题，并保留用户选择
- 电脑端与手机端响应式布局

## 页面结构

当前版本采用“单页入口 + 多个页面视图”的结构。主要页面集中在 `index.html` 中，通过 `data-view` 和 `data-view-target` 完成页面切换。

| 页面名称 | HTML 视图 ID | 主要内容 |
| --- | --- | --- |
| 首页 | `view-home` | 决策阶段、搜索入口、平台介绍 |
| 院校与经验库 | `view-experience` | 院校信息、学生经验、筛选和搜索 |
| 问答中心 | `view-questions` | 提问、回答和历史记录 |
| 我的候选 | `view-compare` | 收藏候选、比较和家庭协同 |
| 信任与认证 | `view-trust` | 身份认证和信息来源规则 |

## 安全与数据处理

- 新注册账号使用随机盐值和 SHA-256 保存密码摘要，不保存新账号的明文密码
- 登录时兼容并迁移早期试用版遗留的明文密码记录
- 用户输入在插入动态 HTML 前进行转义，降低脚本注入风险
- 家庭邀请码使用 `YL-` 前缀加 8 位随机大写字符
- 学生、高中生和大学生可以创建家庭邀请码，家长可以使用邀请码加入
- 家庭关联操作包含角色、邀请码有效性和重复加入检查

这些措施仅用于前端原型阶段的基础保护，不能替代正式后端认证、服务器端权限校验和安全数据库。

## 本地运行

在项目目录运行：

```powershell
python -m http.server 4173
```

然后访问：<http://localhost:4173/>

也可以直接打开 `index.html`，但通过本地 HTTP 服务运行更稳定，并能正常使用依赖安全上下文的浏览器功能。

## 验证建议

1. 注册学生账号，确认可以登录、修改个人资料并生成家庭邀请码。
2. 注册家长账号，输入学生邀请码并确认家庭关联成功。
3. 收藏学校或专业，确认候选列表、对比和状态修改正常。
4. 切换主题及院校页面布局，刷新后确认选择仍然保留。
5. 使用浏览器手机模拟器检查导航栏、表单、弹窗和卡片布局。

## 重要说明

当前项目是静态前端试用版，不是真实的多用户账号系统。账号、问题、收藏、邀请码和认证申请等数据保存在当前浏览器的 `localStorage` 中：

- 更换浏览器、设备或清理浏览器数据后，记录不会同步
- 请勿填写真实密码、证件号码等敏感信息
- 认证申请只演示产品流程，不会连接真实身份核验服务
- 页面中的学校、经验和统计数据为产品展示示例

正式上线前仍需接入后端 API、数据库、短信或邮箱认证、服务端权限校验、身份核验和内容审核。

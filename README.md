### XSS防护

```javascript
// 所有innerHTML都使用escapeHtml
const escapeHtml = (value = "") => 
  String(value).replace(/[&<>"']/g, (char) => 
    ({ "&": "&amp;", "<": "&lt;", ">": "&gt;", 
       '"': "&quot;", "'": "&#39;" })[char]
  );
```
